# The Family Ledger - Android App

WebView app for https://family-ledger-rouge.vercel.app/

## APK build panna
1. Android Studio (Hedgehog or newer) install pannunga.
2. File > Open > indha `FamilyLedger` folder select pannunga.
3. Gradle sync mudiyara varai wait pannunga (first time internet venum).
4. Build > Build Bundle(s) / APK(s) > Build APK(s)
5. APK: app/build/outputs/apk/debug/app-debug.apk

## Website URL maatha
MainActivity.kt-la `homeUrl` change pannunga.
